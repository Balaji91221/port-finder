Connect this laptop

A web page cannot see your ports by itself. Port Finder uses a small helper that runs on your laptop and shows the list only to this page.

  1. Run this in Terminal (downloads the helper and starts it)
  2. Come back here. The page connects by itself in a few seconds. If the browser asks to allow "local network" access, click Allow.

Needs macOS and Python 3. Or download port-helper.py and read it first — it is one short file.
