# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and welcoming. Disagree with ideas, not people.
- No harassment, insults, or personal or political attacks.
- Accept feedback gracefully, and give it kindly.
- Respect people's time: search issues before opening a new one.

## Reporting

If someone breaks these rules, report it privately to the maintainer through a
[GitHub Security Advisory](https://github.com/Balaji91221/port-finder/security/advisories/new)
or a direct message on GitHub ([@Balaji91221](https://github.com/Balaji91221)).
Reports are handled confidentially.

The maintainer may remove, edit or reject comments, commits, code and issues that do not
follow this Code of Conduct, and may ban contributors who repeatedly break it.
